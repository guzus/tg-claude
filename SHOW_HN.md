## Post Content

I built a Telegram bot that lets you control Claude Code from your phone.

**Why:** I wanted to run Claude on my home server and interact with it while commuting or away from my desk.

**Features:**
- Beast Mode: autonomous task execution with iteration until complete
- Repository management (clone, create, switch projects)
- Git operations (commit, push, pull)
- MCP server configuration per repository
- Optional GLM (Z.ai) as alternative to Claude

**Stack:** TypeScript, Bun, Docker

Deploy in one click on Railway or self-host with Docker.
