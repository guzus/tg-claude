### Tagline (60 chars max)


### Description
```
tg-claude is a Telegram bot that connects to Claude Code, letting you run AI-powered coding tasks from your phone.

Features:
• Execute Claude Code tasks via Telegram messages
• Beast Mode: autonomous execution that iterates until the task is complete
• Repository management: clone, create, and switch between projects
• Git operations: commit, push, pull
• MCP server configuration per repository
• GLM support as Claude alternative

Deploy in one click on Railway, or self-host with Docker.

Built for developers who want to leverage Claude Code without being tied to their desk.
```
